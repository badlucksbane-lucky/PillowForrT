# Logo and brand assets

The Stone of Heimdall mark: a six-arc bridge (Bifröst, the bridge Heimdall guards) in sepia tones, with a small watching stone and its one lit eye at its foot. Parchment is the lead presentation; the dark versions are for dark surfaces.

**Licence:** MIT, the same as the project (see `../LICENSE`). Use, modify and share them freely; keep the copyright notice.

| File | Use |
|---|---|
| `logo-parchment.svg` / `.png` | the lead logo, with its parchment background |
| `logo-dark.svg` | the same on a dark background |
| `logo-horizontal-ink.svg` | transparent, dark lettering, for light or parchment pages |
| `logo-horizontal-cream.svg` | transparent, cream lettering, for dark pages |
| `mark.svg`, `mark-512.png` | the mark alone, transparent |
| `app-icon-parchment.svg`, `app-icon-dark.svg`, `apple-touch-icon.png` | the mark on a tile |
| `favicon.ico`, `favicon-16/32/48/64.png` | favicons |
| `social-preview.png`, `social-preview-dark.png` | 1280 x 640 link-preview images (set the repository's social preview from one of these) |

**Colours** (sepia): parchment `#f1e4c8`, ink `#3f2a18`, subtext `#7a5638`, dark `#1b130c`, cream `#e8c98f`. Bridge arcs, outer to inner: `#5b3a21` `#7b502d` `#9b6c3e` `#b98b55` `#d3a96e` `#e8c98f`. Stone `#7a5638`, eye `#f3dba5`.

**Lettering:** set in Cinzel (Copyright 2020 The Cinzel Project Authors, https://github.com/NDISCOVER/Cinzel, SIL Open Font License 1.1). The letters are converted to outlines in the SVGs, so no font is needed and none is shipped here.
